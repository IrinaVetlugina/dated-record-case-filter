## 1. ПОЛНАЯ КАРТА ФАЙЛОВ РЕПОЗИТОРИЯ

### Инфраструктура и код (Python / MCP / Наука)
1. **`case_filter_mcp_server.py`** — **MCP-сервер (Model Context Protocol)** для Claude Desktop, Cursor, Windsurf и корпоративных ИИ-агентов. Блокирует отправку писем и согласование договоров с пассивом, цифрами без базы и резиновыми сроками (время отклика `< 0.5 мс`, без внешних зависимостей).
2. **`case_compiler.py`** — автономный Python-компилятор для проверки текстов и файлов без обращения к LLM.
3. **`pyproject.toml`** — конфигурация для сборки и публикации пакета в PyPI (`pip install case-filter`).
4. **`whitepaper_dated_record_method.md`** — формальный научный препринт на английском языке для загрузки на Zenodo / arXiv (получение DOI).

### Текстовые экшены («МАКРОС-ОС» для любых LLM)
5. **`padezhny-filtr-v1.3.md`** — фундаментальное ядро (депонированный базис).
6. **`macro-os-v4.0-ultimate.md`** — 10-слойный рентген одиночных текстов (`УЛЬТРА:`) + перевод «КАК НАДО».
7. **`macro-os-v5.0-deep-engine.md`** / **`-en.md`** — глубокий аналитик: послойное раздевание текста (`ЛУКОВИЦА:`), перекрёстная сверка двух документов (`СВЕРКА-ПАРА:`) и тест на краях окна (`ВЫРОЖДЕНИЕ:`).
8. **`macro-os-v6.0-architect.md`** / **`-en.md`** — синтез договоров (`КОНСТРУКТОР:`), состязательная атака (`АДВОКАТ ДЬЯВОЛА:`) и защита от промпт-инъекций (`БРОНЯ`).
9. **`macro-os-v7.0-tribunal.md`** / **`-en.md`** — мультиагентный совет (`ТРИБУНАЛ`: Прокурор / Защитник / Судья) и кросс-модельный `АРБИТРАЖ`.

## 2. БЫСТРЫЙ СТАРТ ДЛЯ РАЗРАБОТЧИКОВ (MCP SERVER)

Чтобы подключить «Падежный фильтр» как системный предохранитель в **Claude Desktop** или **Cursor**, добавьте в файл конфигурации (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "case-filter": {
      "command": "python3",
      "args": ["/абсолютный/путь/к/папке/case_filter_mcp_server.py"]
    }
  }
}
```

После перезапуска ИИ-агент получит три системных инструмента:
- `verify_statement` — блокировка галлюцинаций, пассива и цифр без базы до отправки текста.
- `audit_contract_clause` — проверка пунктов договора на «резиновые» сроки и пустое кресло.
- `get_cell_registry` — справочник клеток `1–18 + R6`.

## 3. БЫСТРЫЙ СТАРТ В ОБЫЧНОМ ЧАТЕ (БЕЗ ПРОГРАММИРОВАНИЯ)

1. Откройте новый диалог в ChatGPT, Claude, Gemini или DeepSeek.
2. Скопируйте содержимое файла **`macro-os-v7.0-tribunal.md`** (или `v6.0` / `v4.0`) и отправьте первым сообщением.
3. Используйте команды:
   - `УЛЬТРА: [текст]` — 10-слойный разбор фразы + перевод на человеческий.
   - `СВЕРКА-ПАРА: [Текст А] /// [Текст Б]` — сравнение обещаний в рекламе с текстом договора.
   - `КОНСТРУКТОР: [задача]` — сборка юридически чистого пункта договора без пассива.
   - `АДВОКАТ ДЬЯВОЛА: [документ]` — симуляция атаки юриста оппонента на ваш текст.
   - `ТРИБУНАЛ: [спорный текст]` — суд трёх ролей (Прокурор, Защитник, Судья) с расчётом Индекса расхождения.
   - `ЗЕРКАЛО` — аудит предыдущего ответа самой нейросети с расчётом **Индекса честности в %**.
