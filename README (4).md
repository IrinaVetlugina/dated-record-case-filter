## 🗺️ НАВИГАЦИЯ ПО ФАЙЛАМ ПРОЕКТА (ЧТО ЗА ЧТО ОТВЕЧАЕТ)

Чтобы не запутаться в версиях, используйте эту карту:

1. **Базовое Ядро (Фундамент):**
   - `padezhny-filtr-v1.3.md` — исходный движок, формула события `E = Ω(T) ⟿ σ(O)`, законы кресла, граница творца, шкала времени и реестр базовых клеток.

2. **Точечные микро-фильтры (Отвёртки):**
   - `voice-filter-v0.1.md` (Модуль №01) — Залоговый фильтр (ловит пассив и `-ся/-сь`, ставит `ПУСТОЕ КРЕСЛО`).
   - `aspect-filter-v0.1.md` (Модуль №03) — Эвиденциальный аудитор (проверяет источник знания по 4 уровням).
   - `module-04-contract-auditor.md` (Модуль №04) — Контрактный аудитор обязательств и ТЗ.
   - `ai-truth-mirror-v1.0.md` — Зеркало для ИИ (детектор галлюцинаций самой нейросети с расчётом Индекса честности).

3. **Пакетные конвейеры для нейросетей (От простого к сверхтяжёлому):**
   - `macro-os-v3.0-all-in-one.md` — классический 8-слойный комбайн + Зеркало.
   - `macro-os-v4.0-ultimate.md` — 10-слойный рентген одиночных утверждений + перевод «КАК НАДО» (режим `УЛЬТРА:`).
   - `macro-os-v5.0-deep-engine.md` (+ `-en.md`) — глубокий аналитик: послойное раздевание текста (`ЛУКОВИЦА:`), перекрёстное столкновение двух документов (`СВЕРКА-ПАРА:`) и проверка регламентов на слом (`ВЫРОЖДЕНИЕ:`).
   - `macro-os-v6.0-architect.md` (+ `-en.md`) — автономный архитектор: синтез неуязвимых договоров (`КОНСТРУКТОР:`), враждебная симуляция (`АДВОКАТ ДЬЯВОЛА:`) и защита от промпт-инъекций (`БРОНЯ`).
   - `macro-os-v7.0-tribunal.md` (+ `-en.md`) — высший уровень: мультиагентный совет (`ТРИБУНАЛ:` — Прокурор, Защитник, Судья), кросс-модельный арбитраж между разными ИИ (`АРБИТРАЖ:`) и генератор калибровочных экзаменов (`ЭКЗАМЕН-БАЗА`).

4. **Программный код (Без нейросетей):**
   - `case_compiler.py` — автономный Python-скрипт («Падежный компилятор»). За доли миллисекунды и без расхода токенов проверяет текст по 7 детерминированным шлюзам (пассив, резиновые сроки, цифры без базы, слова-самозванцы, газлайтинг).

## 🚀 БЫСТРЫЙ СТАРТ

### Вариант А: Работа через любую нейросеть (ChatGPT, Claude, Gemini, DeepSeek)
1. Откройте новый чат с ИИ.
2. Загрузите или вставьте текст нужного файла (например, `macro-os-v7.0-tribunal.md`).
3. Запускайте проверки командами:
   - `УЛЬТРА: [фраза или новость]` — 10-слойный рентген + перевод на прямой язык.
   - `СВЕРКА-ПАРА: [Текст А] /// [Текст Б]` — сравнение обещаний из презентации с реальным договором.
   - `ЛУКОВИЦА: [длинная статья]` — отжим воды до сухого ядра фактов `E`.
   - `КОНСТРУКТОР: [задача]` — сборка пункта договора без пассива и лазеек.
   - `АДВОКАТ ДЬЯВОЛА: [ваш текст]` — атака на ваш документ и выдача заплаток.
   - `ТРИБУНАЛ: [спорный пункт]` — разбор тремя ролями (Прокурор / Защитник / Судья).
   - `ЗЕРКАЛО` — аутопсия предыдущего ответа самой нейросети с расчётом Индекса честности в %.

### Вариант Б: Запуск автономного Python-скрипта (`case_compiler.py`)
Не требует интернета, API-ключей и сторонних библиотек (работает на стандартном Python 3.8+):
```bash
python case_compiler.py
```

## 🧬 ЕДИНЫЙ СПРАВОЧНИК СБОЕВ (ЗООПАРК КЛЕТОК 1–18 + R6)

- **Клетка 1 (Запись без акта):** заявление о результате без фактов и тактов оплаты.
- **Клетка 11 (Чужой именительный):** абстракция или запись в кресле деятеля (*«Наука доказала»*).
- **Клетка 13 (Время-самозванец):** время в роли исполнителя (*«время покажет»*).
- **Клетка 14 (Пассив-самозванец):** скрытый субъект за пассивом или `-ся/-сь` (`ПУСТОЕ КРЕСЛО`).
- **Клетка 15 (Экстраполяция за край):** перенос прошлого на будущее без гарантии (`[Р]`).
- **Клетка 16 (Ложная корреляция):** «после этого» выдано за «вследствие этого».
- **Клетка 17 (Цифра-самозванец):** проценты или «разы» без абсолютной начальной базы.
- **Клетка 18 (Логический скачок):** вывод шире посылок, обобщения (*«всегда/никогда»*), газлайтинг.
- **Клетка R6 (Проводка без отправителя):** финансовая цифра без расчётного источника и баланса.
